# PDA 工单撤回交互 Demo

打开 [index.html](./index.html) 即可体验。当前操作者模拟 A 店店员乙，第一张工单由同店店员甲提报。依次点击「处理中」列表第一张工单 →「撤回工单」→「确定撤回」。列表会移除该工单，处理中角标减少；撤回前也可取消。撤回成功后，可用画面外的「打开撤回前的旧链接」查看不可访问状态。

「模拟责任人此刻接单」位于 PDA 画面外，只用于演示并发冲突。先打开第一张工单详情，再点击该按钮，然后继续撤回，会收到「责任人已接单，无法撤回」。点击「重置演示」可重新体验。

## 来源与边界

- 页面视觉参考现有 PDA 工单协作原型：采用其 360px PDA 页面、状态 Tab、灰色业务卡、白色提报卡、橙色主操作与药盒图片；新增「撤回工单」和确认结果状态按本次 PRD 设计。
- 业务规则以本需求 PRD 为准。PDA H5 源码和当前设备生产版本尚未核验，本 Demo 是基于已有原型及代码事实的交互提案，不声称与线上页面逐像素一致。
- 工单编号、门店与店员是合成演示数据。图片来自原型资产；状态只保存在当前浏览器内存，不调用真实接口。接单和撤回的并发胜负在真实系统中必须由后端保证。
